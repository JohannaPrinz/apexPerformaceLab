# insights

Professional interpretation of Measurements — the scientific core of Apex OS.

An Insight is written by a Coach and always records what it is based on.
Evidence is a relation between the Insight and its support, never an object of
its own: it may point to a Measurement, a Video, a Document or a Note.

Heterogeneous evidence is required, not optional — an insight about running
technique rests on a video, not on a number.

## Scope

- Writing and editing Insights while the containing Report is in `DRAFT`
- Linking evidence across Measurements, Videos, Documents and Notes
- Displaying an Insight together with everything that supports it

## Constraints

- Evidence is captured when the Insight is written. It cannot be reconstructed
  afterwards, so recording it is never optional.
- An Insight has no publication state of its own. It freezes together with the
  Report that references it.
