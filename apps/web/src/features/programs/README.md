# programs

Structured coaching plans created inside Apex OS.

A Program is a living coaching resource — it evolves over time and is
independent from published Reports. Changing a Program never affects the
historical integrity of a published Assessment.

Uploaded PDF training plans are **Documents**, not Programs. The distinction is
authorship: a Program is an editable domain object, a Document is a file.

## Scope

- Building and editing Programs
- Revision over the course of a Case
- Assignment along the context ladder (Athlete, Case, Assessment, Module)
- Athlete-facing view of a shared Program

## Constraint

Apex OS is not a training plan generator. A Program is a coach's tool, not an
output the system produces on its own.
